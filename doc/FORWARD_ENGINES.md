# 转发工具与流量统计

面板提供以下转发工具：

| 工具 | 适用范围 | TCP | UDP | 多主机链路 | 目标地址 |
| --- | --- | --- | --- | --- | --- |
| GOST | 通用转发、链式转发、限速 | 支持 | 支持 | 支持 | IP 或域名，可多目标 |
| Realm | 轻量单节点转发 | 支持 | 支持 | 不支持 | 单个 IP 或域名 |
| iptables | Linux 内核 NAT | 支持 | 支持 | 不支持 | 单个 IPv4 |
| nftables | Linux 内核 NAT | 支持 | 支持 | 不支持 | 单个 IPv4 |
| socat | 简单进程转发 | 支持 | 支持 | 不支持 | 单个 IP 或域名 |
| Nginx Stream | 稳定的流式代理 | 支持 | 支持 | 不支持 | 单个 IP 或域名 |

GOST 使用应用层有效载荷计数。其余工具使用节点上的 nftables 包字节计数，因此会包含 IP、TCP 或 UDP 的协议开销。每条外部工具规则都有独立计数表，节点每 5 秒读取一次增量；主控成功接收后才确认该次增量，确认进度会保存在节点磁盘上，节点程序重启后会继续计算未确认的流量。

链路的流量计费模式作用于每个上报窗口：

- **仅出向**：计费流量 = 出站流量。
- **双向合计**：计费流量 = 出站流量 + 入站流量。
- **双向取最大值**：计费流量 = `max(出站流量, 入站流量)`。

数据库分别保存真实入站、真实出站和计费流量。用户配额、链路配额、首页用量图表以及订阅接口都使用计费流量。升级旧数据库时，首次迁移会用已有的入站与出站总和初始化计费流量，避免升级后用量归零。

节点安装或更新脚本会安装 nftables、iptables、socat、Nginx Stream 和 Realm，并开启 IPv4 转发。外部工具当前只允许管理员创建单节点、单目标规则，也不应用 GOST 的用户限速规则。

升级节点后，升级前已经存在的 Realm 规则需要在面板中重新保存一次，用于创建该规则的独立流量计数器。新建规则会自动完成这一步。
